**Card C2  GPIO pin nibble (CRL or CRH)**

```
shift = (pin % 8) * 4          /* each pin owns 4 bits */
register = (pin < 8) ? CRL : CRH
gpio_cfg(GPIOx, pin, NIBBLE);   /* = C1 with width 4 */
```

A hotel corridor: 8 rooms per floor, 4 bits per room. Pins 0-7 are on floor CRL, pins 8-15 on floor CRH.

```
PC13: 13 % 8 = 5, shift = 5 * 4 = 20, register CRH.
PA2 : shift = 2 * 4 = 8,  register CRL.
```

| nibble | meaning |
|---|---|
| 0x0 | analog input |
| 0x4 | floating input |
| 0x8 | input with pull-up or pull-down (ODR bit picks which: 1 = pull-up) |
| 0x2 | output, push-pull, 2 MHz |
| 0x3 | output, push-pull, 50 MHz |
| 0xA | alternate function, push-pull, 2 MHz |
| 0xB | alternate function, push-pull, 50 MHz |
| 0xF | alternate function, open-drain, 50 MHz |

**Card C1  Change a field (clear with a mask, then set)**

```
REG &= ~(MASK << SHIFT);     /* 1. clear the field  */
REG |=  (VALUE << SHIFT);    /* 2. write the value  */

In code:  reg = field_set(reg, SHIFT, WIDTH, VALUE);
```

## Learn (about 30 minutes)

**Clock tree.** The chip starts on the slow internal oscillator (HSI, 8 MHz). To go fast: turn on the crystal (HSE, 8 MHz), wait until it is stable, then feed it into the PLL (a clock multiplier: x9 = 72 MHz), wait until the PLL locks, then switch the system clock to it. Each "wait until" is a flag, so each uses card C3 with a timeout.

**Flash is slow.** Above 48 MHz the flash cannot keep up, so you must insert 2 wait states BEFORE raising the clock. Skip this and the chip crashes.

**Bus dividers.** APB1 (slow bus) is limited to 36 MHz, so it divides by 2. Timers on APB1 get double the clock: 72 MHz. The ADC clock must be 14 MHz or less: 72 / 6 = 12 MHz.

**SysTick** is a down-counter inside the CPU. It counts from LOAD to 0, fires an interrupt, reloads. With LOAD = 71999 it counts 72000 ticks = 1 ms at 72 MHz. The interrupt handler adds 1 to a counter `g_ms`. `millis()` returns it.

**Time never stops wrapping.** `g_ms` is 32 bits: it wraps after about 49 days. Compare times with card C6 (`elapsed`, `reached`), never with `now >= deadline`.

**Why no busy-wait?** A delay loop blocks everything. Instead the loop checks "has my deadline passed?" and does other work meanwhile.

## Worked example: 32 MHz from the internal oscillator, then SysTick

```c
/* WORKED EXAMPLE (M1-04): 32 MHz from the internal oscillator, then a 1 ms SysTick. */
#include "stm32f103.h"
#include "drills.h"

static volatile uint32_t ms;
void SysTick_Handler(void) { ms++; }

int clock32_init(void)
{
    /* HSI (8 MHz) is already running. With PLLSRC = 0 the PLL input is HSI/2 = 4 MHz. */
    FLASH->ACR = field_set(FLASH->ACR, 0, 3, 1);                 /* 1 wait state: 24..48 MHz  */
    RCC->CFGR  = field_set(RCC->CFGR, RCC_CFGR_PLLMUL_Pos, 4, 6);/* PLLMUL 6 = x8 -> 32 MHz   */
    RCC->CR   |= RCC_CR_PLLON;
    if (wait_flag(&RCC->CR, RCC_CR_PLLRDY, 1, 100000u)) return -1;
    RCC->CFGR  = field_set(RCC->CFGR, RCC_CFGR_SW_Pos, 2, 2);    /* SW 2 = PLL                */
    if (wait_flag(&RCC->CFGR, RCC_CFGR_SWS_PLL, 1, 100000u)) return -1;

    SYSTICK->LOAD = 32000000u / 1000u - 1u;                      /* 31999 ticks = 1 ms        */
    SYSTICK->VAL  = 0;
    SYSTICK->CTRL = SYSTICK_ENABLE | SYSTICK_TICKINT | SYSTICK_CLKSRC;
    return 0;
}
```

Same recipe as yours, with different numbers: PLL source is HSI/2 (4 MHz), multiplier x8 = 32 MHz, 1 flash wait state, LOAD = 31999.

## Cheat sheet

| Item | Value |
|---|---|
| RCC CR bits | HSEON bit 16, HSERDY bit 17, PLLON bit 24, PLLRDY bit 25 |
| RCC CFGR fields | SW: shift 0, width 2 (value 2 = PLL). SWS (status): bit 3 set when PLL is in use. PPRE1: shift 8, width 3 (value 4 = divide by 2). ADCPRE: shift 14, width 2 (value 2 = divide by 6). PLLSRC: bit 16 (1 = HSE). PLLMUL: shift 18, width 4 (value 7 = x9) |
| FLASH ACR | LATENCY: shift 0, width 3 (value 2 = two wait states). PRFTBE: bit 4 (prefetch enable) |
| FLASH base / ACR offset | 0x40022000 / 0x00 |
| SysTick base | 0xE000E010: CTRL 0x00, LOAD 0x04, VAL 0x08 |
| SysTick CTRL bits | ENABLE bit 0, TICKINT bit 1, CLKSOURCE bit 2 (1 = CPU clock) |
| SysTick LOAD | clock / tick_hz - 1 = 72000000 / 1000 - 1 = 71999 |
| CFGR word this issue builds | PLLSRC `RCC_CFGR_PLLSRC_HSE` + PLLMUL 7 + PPRE1 4 + ADCPRE 2 = 0x001D8400 (SW is NOT in it) |
| Order of `clock_init` | HSEON, wait HSERDY, FLASH latency 2, CFGR = word, PLLON, wait PLLRDY, SW = 2, wait SWS, SysTick |
| Names in the header (given) | `RCC_CR_HSEON`, `RCC_CR_HSERDY`, `RCC_CR_PLLON`, `RCC_CR_PLLRDY`, `RCC_CFGR_SW_Pos`, `RCC_CFGR_SWS_PLL`, `RCC_CFGR_PPRE1_Pos`, `RCC_CFGR_ADCPRE_Pos`, `RCC_CFGR_PLLSRC_HSE`, `RCC_CFGR_PLLMUL_Pos`, `FLASH_ACR_LATENCY_Pos`, `FLASH_ACR_PRFTBE`, `SYSTICK_ENABLE`, `SYSTICK_TICKINT`, `SYSTICK_CLKSRC`, `SYSCLK_HZ` |

Cards C1, C3, C6:

```
C1: reg = field_set(reg, SHIFT, WIDTH, VALUE);
C3: while (tries--) { if (flag is in the wanted state) return 0; }  return -1;
C6: elapsed = now - start;   reached = (int32_t)(now - deadline) >= 0;
```
