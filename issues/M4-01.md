## Learn (about 30 minutes)

**What a trigger does.** A scope shows a repeating signal as a still picture because every sweep starts at the same point of the wave: where it crosses a chosen level going up (rising) or going down (falling). Without it the picture slides around.

**Detecting a crossing.** Look at two neighbours. Rising: the earlier sample is below the level and the later one is at or above it. Falling: the earlier sample is at or above the level, the later one below. So the loop starts at index 1 (it needs a "previous" sample).

**Why only the first 128 samples?** The screen shows 128 samples starting at the trigger. The buffer has 256. If the trigger is found in the first 128, the window `[idx, idx + 127]` always fits.

**No trigger = auto mode.** If no crossing exists (a flat line, or a signal that never reaches the level), start at sample 0 so you still see something.

**Level in counts.** The user sets the level in millivolts (default 1650 mV). Samples are counts, so convert once: `mv * 4095 / 3300`, using card C5.

## Worked example: `first_above()`

```c
/* WORKED EXAMPLE (M4-01): first index where the value goes above a threshold, or -1. */
#include <stdint.h>
int first_above(const uint16_t *a, unsigned n, uint16_t thr)
{
    for (unsigned i = 0; i < n; i++) {
        if (a[i] > thr) return (int)i;     /* found: stop right here   */
    }
    return -1;                             /* looked at everything: none */
}
```

`trig_find` is the same loop with a two-sample test, starting at 1, and an extra `rising` switch.

## Cheat sheet

| Item | Value |
|---|---|
| Counts per mV | 4095 / 3300 |
| `mv_to_counts` examples | 0 -> 0, 1000 -> 1240, 1650 -> 2047, 3300 -> 4095 |
| Rising crossing at i | `s[i-1] < level && s[i] >= level` |
| Falling crossing at i | `s[i-1] >= level && s[i] < level` |
| Loop | `for (unsigned i = 1; i < n_scan; i++)` |
| No crossing | return -1 |
| `trig_start` | negative index -> 0, otherwise the index itself |
| In the scope | scan 128 samples (`n_scan` = 128), level = `mv_to_counts(ui.level_mv)` |

### STEP 2 · TODO M4-01/2 · `trig_find` · [src: M4-01 step 2, worked example first_above]
- **WHAT:** Find the first rising or falling crossing.
- **INGREDIENTS:** the two-neighbour tests from the cheat sheet.
- **HOW (recipe):**
  1. Loop `i` from 1 up to (not including) `n_scan`.
  2. If `rising` is true: when the previous sample (`i - 1`) is below `level` AND sample `i` is at or above it, return `i`.
  3. Otherwise (falling): when the previous sample is at or above `level` AND sample `i` is below it, return `i`.
  4. After the loop ends with no crossing, return -1.

| example | result |
|---|---|
| `{0,0,100,200,300,...}`, level 150, rising | 3 |
| `{300,200,100,0,...}`, level 150, falling | 2 |
| `{200,300,400,...}`, level 150, rising | -1 (starts above) |
| crossing at index 5 but `n_scan` = 5 | -1 |
- **WHERE:** `src/trigger.c`, `trig_find`. Delete the stub lines.
- **CHECK:** `make t T=m4_01` -> `test_rising`, `test_falling`, `test_none`, `test_equal_level` all `:PASS`.
