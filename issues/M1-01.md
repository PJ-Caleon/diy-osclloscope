## Warm-up (10 minutes, code only): the pointer mirror

There are no drills yet, so warm up on your weak spot. `&` asks "where does it live?" and gives an address. `*` asks "who is home at that address?" and gives the value.

1. Make a scratch file: type `mkdir -p scratch` then open `scratch/ptr.c` and copy this in:

```c
/* Pointer mirror drill. & = "address of".  * = "value at that address". */
#include <stdio.h>
int main(void)
{
    int cookies = 5;
    int *jar = &cookies;       /* jar holds the ADDRESS of cookies          */
    *jar = *jar + 2;           /* read the value at jar, add 2, store back  */
    printf("cookies=%d\n", cookies);
    printf("same=%d\n", jar == &cookies);
    return 0;
}
```

2. BEFORE you run it, write down what you think it prints.
3. Run: `gcc scratch/ptr.c -o scratch/ptr && ./scratch/ptr`. Expect: `cookies=7` then `same=1`.
4. Change `*jar = *jar + 2;` to `*jar = *jar * 3;`. Predict, then run. Expect `cookies=15`.
5. Put the original line back and add two lines after it: `int *other = jar;` and `*other = 1;`. Predict, then run. Expect `cookies=1`.

| Symbol | Read it as |
|---|---|
| `&cookies` | the address of the variable `cookies` |
| `int *jar` | `jar` holds an address of an int |
| `*jar` | the int that lives at that address |


## Learn (about 30 minutes)

**A peripheral is a row of mailboxes.** Each mailbox is a 32-bit register at a fixed street address. Writing a number into it flips switches inside the chip. Reading it shows what the chip is doing.

**A struct lays mailboxes side by side.** If a struct holds 32-bit members, the first sits at offset 0x00, the next at 0x04, then 0x08 and so on. So the struct IS the register map. Cast the base address to a pointer to the struct and `GPIOC->ODR` means "the mailbox at base + 0x0C".

**`volatile`** tells the compiler: "this value can change behind your back. Do not skip reads or writes." Every register member needs it.

**Pointers, your weak spot.** `&x` asks "where does x live?" and gives an address. `*p` asks "who is home at address p?" and gives the value. Read `*(volatile uint32_t *)0x40021014u` as: "treat this number as an address, then go to that address."

**Clock gates.** At power-on most peripherals have their clock switched off to save power. A register you write to an unclocked peripheral does nothing. So the first line of every driver turns the clock on in RCC.

**GPIO pins.** Each pin has a 4-bit setup nibble. Eight nibbles fit in a 32-bit register: CRL holds pins 0 to 7, CRH holds pins 8 to 15. That is card C2.

**BSRR is a set/clear mailbox.** Writing a 1 to bit n (low half) makes pin n HIGH. Writing a 1 to bit n+16 (high half) makes pin n LOW. Writing 0 changes nothing. No read-modify-write needed.

**The LED is active-low.** The on-board LED on PC13 lights when the pin is LOW.

**The fake chip.** The tests build with `-DUNIT_TEST`. Then `GPIOC` and `RCC` point at two ordinary structs in RAM (`fake_gpioc`, `fake_rcc`) instead of real addresses. Your code runs on your PC and the tests read the fake registers afterwards.

## Worked example: the CRC unit (a different peripheral, same recipe)

```c
/* WORKED EXAMPLE (M1-01): the CRC unit. Same recipe as GPIO and RCC, different peripheral. */
#include <stdint.h>
#define BIT(n) (1u << (n))

typedef struct {
    volatile uint32_t DR;    /* 0x00  write a word in, read the result out */
    volatile uint32_t IDR;   /* 0x04  one spare byte                        */
    volatile uint32_t CR;    /* 0x08  bit 0 = RESET                         */
} CRC_TypeDef;

#define CRC_BASE   0x40023000u
#define CRC        ((CRC_TypeDef *)CRC_BASE)       /* number -> pointer to struct */
#define RCC_AHBENR (*(volatile uint32_t *)0x40021014u)
#define CRCEN      BIT(6)                          /* clock gate bit in AHBENR    */

void crc_init(void)
{
    RCC_AHBENR |= CRCEN;            /* 1. clock on                              */
    CRC->CR = 1u;                   /* 2. reset: result goes back to 0xFFFFFFFF */
}

uint32_t crc_words(const uint32_t *p, unsigned n)
{
    for (unsigned i = 0; i < n; i++) {
        CRC->DR = p[i];             /* 3. feed one word                         */
    }
    return CRC->DR;                 /* 4. read the result                       */
}
```

Read it like this: struct (offsets 0, 4, 8) -> base address -> a macro that casts it to a pointer -> clock bit -> functions that write and read members.

## Cheat sheet (everything this issue needs)

| Item | Value |
|---|---|
| GPIOC base | 0x40011000 |
| RCC base | 0x40021000 |
| GPIOA / GPIOB base (given) | 0x40010800 / 0x40010C00 |

GPIO register offsets (each 32 bit):

| Name | CRL | CRH | IDR | ODR | BSRR | BRR | LCKR |
|---|---|---|---|---|---|---|---|
| Offset | 0x00 | 0x04 | 0x08 | 0x0C | 0x10 | 0x14 | 0x18 |

RCC register offsets (each 32 bit):

| Name | CR | CFGR | CIR | APB2RSTR | APB1RSTR | AHBENR | APB2ENR | APB1ENR | BDCR | CSR |
|---|---|---|---|---|---|---|---|---|---|---|
| Offset | 0x00 | 0x04 | 0x08 | 0x0C | 0x10 | 0x14 | 0x18 | 0x1C | 0x20 | 0x24 |

| Fact | Value |
|---|---|
| APB2ENR bit for GPIOA / GPIOB / GPIOC | bit 2 / bit 3 / bit 4 (`IOPCEN` = bit 4) |
| LED pin | PC13 (pin 13), active-low |
| Nibble for PC13 | pin 13 -> CRH, shift (13 % 8) * 4 = 20 |
| Nibble value: output push-pull 2 MHz | 0x2 |
| CRH after reset | 0x44444444 (all inputs, floating) |
| BSRR to set pin n HIGH | bit n |
| BSRR to set pin n LOW | bit n + 16 |
| LED ON = pin LOW | BSRR = BIT(13 + 16) = 0x20000000 |
| LED OFF = pin HIGH | BSRR = BIT(13) = 0x00002000 |
| `BIT(n)` | `1u << n` (given in the header) |

Cards C1 and C2 (full text in the book's Pattern Cards chapter):

```
C1:  REG &= ~(MASK << SHIFT);  REG |= (VALUE << SHIFT);     MASK = (1 << WIDTH) - 1
C2:  shift = (pin % 8) * 4;    register = (pin < 8) ? CRL : CRH
```
