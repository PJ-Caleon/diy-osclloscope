## Learn (about 30 minutes)

**PWM** = a pin that switches on and off very fast. The fraction of time it is ON is the duty cycle. 25 % duty at 3.3 V averages 0.825 V.

**A timer makes it.** The counter counts up from 0 to ARR, then restarts. The compare register CCR sets the switch point: the pin is HIGH while the counter is below CCR (in PWM mode 1). Period = (ARR + 1) ticks. Duty = CCR / (ARR + 1).

**Numbers.** Timer clock 72 MHz. PSC = 71 divides by 72: 1 MHz. ARR = 999: 1000 ticks = 1 kHz. CCR = 250: 25 % duty.

**Pin.** TIM2 channel 2 is on PA1 (alternate function, push-pull; nibble 0xA = 2 MHz). The pin belongs to the timer, not to GPIO.

**Preload.** Set OC2PE so a new CCR value only takes effect at the next period, with no glitch.

**Why loop it into the ADC?** It is your free signal generator. You have no function generator and no scope: this is the only way to check the scope. PA1 only ever goes between 0 V and 3.3 V, which is exactly what PA2 tolerates.

## Worked example: TIM3 PWM on PA6

```c
/* WORKED EXAMPLE (M2-03): PWM on TIM3 channel 1, pin PA6, 20 kHz, 30 % duty. */
#include "stm32f103.h"
#include "drills.h"

#define TIM_CCMR1_OC1PE     BIT(3)
#define TIM_CCMR1_OC1M_Pos  4u            /* 3 bits: 6 = PWM mode 1 */
#define TIM_CCER_CC1E       BIT(0)

void pwm_pa6_start(void)
{
    RCC->APB2ENR |= RCC_APB2ENR_IOPAEN;                 /* 1. clocks                       */
    RCC->APB1ENR |= RCC_APB1ENR_TIM3EN;
    gpio_cfg(GPIOA, 6, 0xA);                            /* 2. PA6 alternate push-pull      */
    TIM3->PSC = 0u;                                     /* 3. 72 MHz / 3600 = 20 kHz       */
    TIM3->ARR = 3599u;
    TIM3->CCMR1 = field_set(TIM3->CCMR1, TIM_CCMR1_OC1M_Pos, 3, 6) | TIM_CCMR1_OC1PE;
    TIM3->CCR1 = mul_div(3600u, 30u, 100u);             /*    30 % of 3600 = 1080          */
    TIM3->CCER |= TIM_CCER_CC1E;
    TIM3->EGR = TIM_EGR_UG;                             /* 4. start                        */
    TIM3->CR1 |= TIM_CR1_CEN;
}
```

Same recipe with different numbers: channel 1 (OC1M at shift 4, OC1PE bit 3, CC1E bit 0), pin PA6, 20 kHz, 30 %.

## Cheat sheet

| Item | Value |
|---|---|
| TIM2 base | 0x40000000. CR1 0x00, EGR 0x14, CCMR1 0x18, CCER 0x20, PSC 0x28, ARR 0x2C, CCR1 0x34, CCR2 0x38 |
| TIM2 clock | `RCC->APB1ENR` bit 0 (`RCC_APB1ENR_TIM2EN`); GPIOA clock APB2ENR bit 2 |
| Pin PA1 | CRL, shift 4, nibble 0xA |
| CCMR1 (channel 2) | OC2M: shift 12 width 3 value 6 (PWM mode 1). OC2PE: bit 11 |
| CCER | CC2E bit 4 (output enable for channel 2) |
| Start | EGR UG bit 0, CR1 CEN bit 0 |
| Numbers | PSC 71, ARR 999 |
| `pwm_ccr(arr, percent)` | `mul_div(arr + 1, percent, 100)` -> 250 for 25 % |
| Duty table | 0 % -> 0, 25 % -> 250, 50 % -> 500, 75 % -> 750, 100 % -> 1000 |
| Names in the header (given) | `RCC_APB2ENR_IOPAEN`, `RCC_APB1ENR_TIM2EN`, `TIM_CCMR1_OC2M_Pos`, `TIM_CCMR1_OC2PE`, `TIM_CCER_CC2E`, `TIM_EGR_UG`, `TIM_CR1_CEN` |
| Capture at 32 kSPS | 256 samples = 8 periods of 1 kHz. 25 % duty: about 64 samples above 2048 (allow 56 to 72) |
| Wire | jumper from PA1 to PA2 |
| `count_above(s, n, thr)` | how many of `s[0..n-1]` are greater than `thr` |

| If it fails, look here | Likely cause |
|---|---|
| `high` is 0 with the jumper in | no PWM: `CC2E` missing, or PA1 nibble is not 0xA |
| `high` is always 256 | PWM stuck high: OC2M value not 6, or CCR2 not set |
| frequency wrong | PSC and ARR: 72 MHz / 72 / 1000 = 1 kHz |
| `high` about 128 at 25 % | CCR2 still 500 from `pwm_init`: call `pwm_set_duty(25u)` |
| analog values near 2000 with no jumper | a floating pin: wire it |
