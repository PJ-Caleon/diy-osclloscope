## Learn (about 30 minutes)

**A scope needs samples at a steady rate.** Loops with delays jitter. Hardware does it exactly: a timer ticks, each tick starts one ADC conversion (a "trigger"), and DMA moves each result into memory. The CPU does nothing during the capture.

**The chain.** TIM3 counts. Each time it overflows (update event) it sends a pulse out the "trigger output" (TRGO). The ADC is set to start a conversion on TIM3 TRGO (EXTSEL = 4). At the end of each conversion the ADC asks DMA for help (DMA bit). DMA channel 1 copies `ADC1->DR` into the next slot of `g_cap`, 256 times, and sets the transfer-complete flag.

**DMA is a delivery driver.** You give it: where from (CPAR), where to (CMAR), how many (CNDTR), how wide (16 bits), and "move to the next slot each time" (MINC). It works while you cook.

**Sample rate = timer overflow rate.** Timer clock 72 MHz. `ticks = 72,000,000 / fs`. The reload register ARR is only 16 bits (max 65535). Most rates fit with prescaler 0: ARR = ticks - 1. The slowest rate (800 Hz) needs 90000 ticks: too big, so the prescaler divides by 2 first.

**Order matters.** Configure the timer first. Setting the update-generate bit (UG) fires one update event: do that BEFORE the ADC is routed to the timer, or you capture one stray sample. Then arm DMA. Then route the ADC. Start the timer last.

**One shot.** DMA runs in normal mode: after 256 transfers it stops and sets TCIF1. You poll TCIF1 (card C3).

## Worked example: DMA memory-to-memory copy

```c
/* WORKED EXAMPLE (M2-02): DMA memory-to-memory copy on channel 2 (channel 1 is the ADC's). */
#include "stm32f103.h"
#include "drills.h"

#define DMA_CCR_PINC     BIT(6)
#define DMA_CCR_MEM2MEM  BIT(14)
#define DMA_ISR_TCIF2    BIT(5)             /* channel 2 transfer-complete flag */

int dma_copy_words(uint32_t *dst, const uint32_t *src, uint32_t n)
{
    RCC->AHBENR |= RCC_AHBENR_DMA1EN;                          /* 1. clock                    */
    DMA1->IFCR = 0xFu << 4;                                    /* 2. clear channel-2 flags    */
    DMA1->ch[1].CPAR  = (uint32_t)(uintptr_t)src;              /*    source (the "peripheral") */
    DMA1->ch[1].CMAR  = (uint32_t)(uintptr_t)dst;              /*    destination              */
    DMA1->ch[1].CNDTR = n;                                     /*    how many items           */
    uint32_t ccr = field_set(0u, DMA_CCR_PSIZE_Pos, 2, 2);     /* 3. 32-bit on both sides     */
    ccr = field_set(ccr, DMA_CCR_MSIZE_Pos, 2, 2);
    DMA1->ch[1].CCR = ccr | DMA_CCR_MEM2MEM | DMA_CCR_PINC | DMA_CCR_MINC | DMA_CCR_EN; /* 4. go */
    if (wait_flag(&DMA1->ISR, DMA_ISR_TCIF2, 1, 100000u)) return -1;  /* 5. wait for done     */
    DMA1->IFCR = DMA_ISR_TCIF2;                                /*    clear the flag           */
    DMA1->ch[1].CCR &= ~DMA_CCR_EN;
    return 0;
}
```

Same recipe: clock, clear flags, addresses, count, field setup (card C1), enable, wait on TCIF (card C3). Yours uses channel 1, a peripheral address (`&ADC1->DR`), and 16-bit sizes.

## Cheat sheet

| Item | Value |
|---|---|
| DMA1 base | 0x40020000. ISR 0x00, IFCR 0x04. Channel 1 starts at 0x08: CCR 0x08, CNDTR 0x0C, CPAR 0x10, CMAR 0x14 (each channel is 0x14 bytes). In code: `DMA1->ch[0].CCR` |
| DMA clock | `RCC->AHBENR` bit 0 (`RCC_AHBENR_DMA1EN`) |
| DMA CCR bits | EN bit 0, MINC bit 7, PSIZE shift 8 width 2, MSIZE shift 10 width 2 (value 1 = 16 bit). DIR stays 0 (peripheral to memory); CIRC stays 0 (one shot) |
| DMA flags (channel 1) | ISR bit 1 = TCIF1 (transfer complete). IFCR: write 0xF to clear all four channel-1 flags |
| TIM3 base | 0x40000400. CR1 0x00, CR2 0x04, EGR 0x14, SR 0x10, PSC 0x28, ARR 0x2C |
| TIM3 clock | `RCC->APB1ENR` bit 1 (`RCC_APB1ENR_TIM3EN`) |
| TIM bits | CR1 CEN bit 0. CR2 MMS shift 4 width 3 (value 2 = update event to TRGO). EGR UG bit 0 |
| ADC CR2 | EXTSEL shift 17 width 3 (value 4 = TIM3 TRGO). DMA bit 8. EXTTRIG bit 20 |
| `sampler_timing` | `ticks = 72000000 / fs;  psc = (ticks - 1) / 65536;  arr = ticks / (psc + 1) - 1;` |
| Rates | 160000 -> psc 0 arr 449; 32000 -> 0, 2249; 1600 -> 0, 44999; 800 -> psc 1, arr 44999 |
| Address of a register | `(uint32_t)(uintptr_t)&ADC1->DR` (the cast turns an address into a number for CPAR) |
| Buffer | `g_cap` (256 x uint16), `SAMPLE_COUNT` = 256 |
| Names in the header (given) | `DMA_CCR_EN`, `DMA_CCR_MINC`, `DMA_CCR_PSIZE_Pos`, `DMA_CCR_MSIZE_Pos`, `DMA_ISR_TCIF1`, `TIM_CR1_CEN`, `TIM_CR2_MMS_Pos`, `TIM_EGR_UG`, `ADC_CR2_DMA`, `ADC_CR2_EXTSEL_Pos`, `ADC_CR2_EXTTRIG` |

### STEP 1 · TODO M2-02/1 · `sampler_timing` · card C5 flavour · [src: M2-02 step 1]
- **WHAT:** Turn a sample rate into timer prescaler and reload values.
- **INGREDIENTS:** 72000000 (`SYSCLK_HZ`), 65536.
- **HOW:**

```
uint32_t ticks = SYSCLK_HZ / <FS>;
*<PSC> = (ticks - 1u) / 65536u;
*<ARR> = ticks / (*<PSC> + 1u) - 1u;
```

| fs | ticks | psc | arr |
|---|---|---|---|
| 160000 | 450 | 0 | 449 |
| 32000 | 2250 | 0 | 2249 |
| 1600 | 45000 | 0 | 44999 |
| 800 | 90000 | 1 | 44999 |

`psc` and `arr` are pointers: `*psc = ...` stores the answer where the caller wants it.

### STEP 4 · TODO M2-02/4 · DMA setup · cards C1 + C5 flavour · [src: M2-02 step 4, card C1]
- **WHAT:** Tell DMA channel 1 where to read, where to write, and how many.
- **INGREDIENTS:** cheat sheet DMA rows.
- **HOW:**

```
DMA1->IFCR = <CLEAR ALL>;
DMA1->ch[0].CPAR  = <WHERE FROM>;
DMA1->ch[0].CMAR  = <WHERE TO>;
```

| placeholder | value |
|---|---|
| CLEAR ALL | `0xFu` (the four channel-1 flags) |

| HOW MANY | `SAMPLE_COUNT` |
| INCREMENT BIT / ENABLE BIT | `DMA_CCR_MINC` / `DMA_CCR_EN` |

| field | shift | width | value |
|---|---|---|---|
| PSIZE | `DMA_CCR_PSIZE_Pos` (8) | 2 | 1 (16 bit) |
| MSIZE | `DMA_CCR_MSIZE_Pos` (10) | 2 | 1 (16 bit) |

### STEP 5 · TODO M2-02/5 · route the ADC and start · card C1 · [src: M2-02 step 5, card C1]
- **WHAT:** Make the ADC start on TIM3 TRGO and use DMA, then start the timer.
- **INGREDIENTS:** EXTSEL = 4, `ADC_CR2_DMA`, `ADC_CR2_EXTTRIG`, `TIM_CR1_CEN`.
- **HOW:**

```
ADC1->CR2 = field_set(ADC1->CR2, <EXTSEL SHIFT>, 3u, <VALUE>);
ADC1->CR2 |= ADC_CR2_DMA | ADC_CR2_EXTTRIG;
TIM3->CR1 |= TIM_CR1_CEN;
```

| field | shift | width | value |
|---|---|---|---|
| EXTSEL | `ADC_CR2_EXTSEL_Pos` (17) | 3 | 4 (TIM3 TRGO) |

`adc_init` left EXTSEL = 7. Because `field_set` clears first, 7 becomes 4. Without the clear, 7 OR 4 = 7 and you would stay on software start. That is why card C1 clears first.

| `dt` at `sampler_start(32000u)` | 8 or 9 (milliseconds) |
| `sampler_start(800u)` | `dt` about 320 (256 / 800 = 0.32 s) and `rc` still 0 |

| If it fails, look here | Likely cause |
|---|---|
| `rc` = -1 | DMA never finished: ADC not routed to TIM3 (EXTSEL 4, EXTTRIG), DMA bit missing, or TIM3 not started (CEN) |
| `dt` is 0 | the capture finished instantly: stale TCIF1 flag. Clear flags with `IFCR = 0xF` before arming |
| samples all 0 | the ADC is not ON: did `adc_init` run first? |
| first sample looks odd | UG was written after the ADC was routed: keep the order of STEPS 3 to 5 |
| every sample twice as old as expected | the sample rate is half: check `psc`/`arr` against the table |
| `dt` wrong at 800 Hz | prescaler missing: ARR cannot hold 90000 |
