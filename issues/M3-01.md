## Learn (about 30 minutes)

**I2C is two wires, many devices.** SCL is the clock, SDA is the data. Both are open-drain: a device only pulls the line LOW, and pull-up resistors (already on your OLED module) pull it HIGH. Every device has a 7-bit address. Your OLED answers at 0x3C.

**One write transaction:**

1. START (SDA falls while SCL is high).
2. Send the address in the top 7 bits plus a 0 write bit: `addr << 1`.
3. The device pulls SDA low for one bit: ACK ("I am here"). No pull = NACK ("nobody home").
4. Send data bytes, each followed by an ACK.
5. STOP.

**The peripheral does the wiggling.** You set START in CR1 and wait for SB (start sent) in SR1. You write the address to DR and wait for ADDR (address sent and acknowledged) or AF (acknowledge failure = NACK). Reading SR1 then SR2 clears ADDR. You write bytes to DR when TXE is set. After the last byte wait for BTF (byte transfer finished), then set STOP.

**Every wait needs a timeout** (card C3). A missing device or a stuck bus must never hang your scope. On any timeout: send STOP and return an error code.

**Speed.** I2C clock = pclk / (3 x CCR) in fast mode with DUTY 0. 36 MHz / (3 x 30) = 400 kHz. In standard mode it is pclk / (2 x CCR): CCR 180 gives 100 kHz. CR2 FREQ tells the peripheral the bus clock in MHz (36). TRISE is the maximum rise time in clock ticks plus one: 12 for fast mode, 37 for standard mode.

**Bus scan.** Try every address from 0x08 to 0x77 with a zero-length write. An ACK means a device lives there.

## Worked example: SPI1 transmit with timeouts

```c
/* WORKED EXAMPLE (M3-01): SPI1 transmit, every wait has a timeout. Same shape as the I2C write. */
#include "stm32f103.h"
#include "drills.h"

typedef struct { volatile uint32_t CR1, CR2, SR, DR; } SPI_TypeDef;      /* 0x00 0x04 0x08 0x0C */
#define SPI1 ((SPI_TypeDef *)0x40013000u)
#define RCC_APB2ENR_SPI1EN BIT(12)
#define SPI_CR1_MSTR BIT(2)
#define SPI_CR1_SPE  BIT(6)
#define SPI_CR1_SSI  BIT(8)
#define SPI_CR1_SSM  BIT(9)
#define SPI_SR_TXE   BIT(1)
#define SPI_SR_BSY   BIT(7)

void spi1_init(void)
{
    RCC->APB2ENR |= RCC_APB2ENR_IOPAEN | RCC_APB2ENR_SPI1EN;   /* 1. clocks               */
    gpio_cfg(GPIOA, 5, 0xB);                                   /* 2. PA5 SCK  alt push-pull */
    gpio_cfg(GPIOA, 7, 0xB);                                   /*    PA7 MOSI alt push-pull */
    SPI1->CR1 = field_set(0u, 3, 3, 4)                         /* 3. baud: BR field = 4 -> /32 */
              | SPI_CR1_MSTR | SPI_CR1_SSM | SPI_CR1_SSI;
    SPI1->CR1 |= SPI_CR1_SPE;                                  /* 4. start                */
}

int spi1_send(const uint8_t *buf, unsigned len)
{
    for (unsigned i = 0; i < len; i++) {
        if (wait_flag(&SPI1->SR, SPI_SR_TXE, 1, 20000u)) return -1;   /* 5. wait: room?  */
        SPI1->DR = buf[i];
    }
    if (wait_flag(&SPI1->SR, SPI_SR_BSY, 0, 20000u)) return -1;       /*    wait: all sent */
    return 0;
}
```

Same shape as your `i2c_write`: setup (card C4), then each wait guarded by `wait_flag` (card C3) that returns an error instead of hanging.

## Cheat sheet

| Item | Value |
|---|---|
| I2C1 base | 0x40005400. CR1 0x00, CR2 0x04, DR 0x10, SR1 0x14, SR2 0x18, CCR 0x1C, TRISE 0x20 |
| Clock bits | GPIOB: APB2ENR bit 3. I2C1: APB1ENR bit 21 |
| Pins | PB6 (SCL) is CRL shift 24; PB7 (SDA) is CRL shift 28. Nibble 0xF = alternate open-drain 50 MHz |
| CR1 bits | PE bit 0, START bit 8, STOP bit 9 |
| CR2 | FREQ: shift 0, width 6, value 36 |
| CCR | bit 15 = F/S (1 = fast), bit 14 = DUTY (0), bits 11:0 = CCR value. Fast 400 kHz: `I2C_CCR_FS \| i2c_ccr(36000000, 400000, 1)` = 30. Standard 100 kHz: 180 |
| TRISE | 12 (400 kHz). 37 (100 kHz) |
| SR1 bits | SB bit 0, ADDR bit 1, BTF bit 2, TXE bit 7, AF bit 10 |
| SR2 bit | BUSY bit 1 |
| `i2c_ccr(pclk, scl, fast)` | `pclk / ((fast ? 3 : 2) * scl)` -> 30, 180 |
| Error codes (given) | `I2C_OK` 0, `I2C_ERR_TIMEOUT` -1, `I2C_ERR_NACK` -2, `I2C_ERR_BUSY` -3 |
| Tries per wait | `I2C_TRIES` (20000, given) |
| Write order | wait BUSY=0, START, wait SB, DR = addr << 1, wait ADDR or AF, if AF: clear AF, STOP, return NACK; read SR1, read SR2; each byte: wait TXE, DR = byte; wait BTF (only if len > 0); STOP |
| Clear AF | `I2C1->SR1 &= ~I2C_SR1_AF;` |
| Read to clear ADDR | `(void)I2C1->SR1; (void)I2C1->SR2;` |
| OLED wiring | SCL to PB6, SDA to PB7, VCC to 3V3, GND to GND |
| Scan range | 0x08 to 0x77 inclusive |
| Names in the header (given) | `RCC_APB2ENR_IOPBEN`, `RCC_APB1ENR_I2C1EN`, `I2C_CR1_PE`, `I2C_CR1_START`, `I2C_CR1_STOP`, `I2C_SR1_SB`, `I2C_SR1_ADDR`, `I2C_SR1_BTF`, `I2C_SR1_TXE`, `I2C_SR1_AF`, `I2C_SR2_BUSY`, `I2C_CCR_FS` |

Cards C1, C2, C3:

```
C1: reg = field_set(reg, SHIFT, WIDTH, VALUE);
C2: gpio_cfg(GPIOx, pin, NIBBLE);
C3: if (wait_flag(&REG, MASK, WANT_SET, TRIES)) { /* timed out */ }
```

### STEP 3 · TODO M3-01/3 · `i2c_write` · card C3 five times · [src: M3-01 step 3, card C3]
- **WHAT:** Send `len` bytes to a device, never hang.
- **INGREDIENTS:** cheat sheet "Write order".
- **HOW:** (the shape; fill each `<...>` from the table)

```
if (wait_flag(&I2C1->SR2, <BUSY>, 0, I2C_TRIES) != 0) return I2C_ERR_BUSY;
I2C1->CR1 |= <START>;
if (wait_flag(&I2C1->SR1, <SB>, 1, I2C_TRIES) != 0) goto timeout;
I2C1->DR = (uint32_t)(addr << 1);
if (wait_flag(&I2C1->SR1, <ADDR> | <AF>, 1, I2C_TRIES) != 0) goto timeout;
if (I2C1->SR1 & <AF>) {
    I2C1->SR1 &= ~<AF>;
    I2C1->CR1 |= <STOP>;
    return I2C_ERR_NACK;
}
(void)I2C1->SR1;  (void)I2C1->SR2;
for (uint16_t i = 0; i < len; i++) {
    if (wait_flag(&I2C1->SR1, <TXE>, 1, I2C_TRIES) != 0) goto timeout;
    I2C1->DR = buf[i];
}
if (len > 0u && wait_flag(&I2C1->SR1, <BTF>, 1, I2C_TRIES) != 0) goto timeout;
I2C1->CR1 |= <STOP>;
return I2C_OK;
timeout:
I2C1->CR1 |= <STOP>;
return I2C_ERR_TIMEOUT;
```

| START / STOP | `I2C_CR1_START` / `I2C_CR1_STOP` |
| SB, ADDR, AF, TXE, BTF | `I2C_SR1_SB`, `I2C_SR1_ADDR`, `I2C_SR1_AF`, `I2C_SR1_TXE`, `I2C_SR1_BTF` |

| If it fails, look here | Likely cause |
|---|---|
| nothing found, OLED wired | SCL and SDA swapped, or VCC not on 3V3, or the module's pins are in a different order (read its silkscreen) |
| scan hangs | a wait without `wait_flag`, so no timeout |
| every address "found" | `AF` is not checked: ADDR is set, AF is not |
| `i2c: 61` instead of 60 | address-shifted twice: only `addr << 1` goes to DR |
| works once then fails | STOP missing after a NACK (the bus stays busy) |
| always BUSY | the bus is stuck: power-cycle the board |
