## Learn (about 30 minutes)

**Everything is pixels.** Grid, text and waveform are three loops that call `fb_pixel`.

**The grid** is dots, so it does not hide the trace. Eight divisions across (16 px each), six down (8 px each, rows 16 to 63).

**Text from a table.** The font is 5 columns by 7 rows per character, stored as 5 bytes (one per column). Bit 0 of a column byte is the TOP row. To draw: for each column 0 to 4, for each row 0 to 6, if the bit is set, plot a pixel at (x + col, y + row). Move 6 pixels right for the next character (5 + 1 gap). Characters 32 (space) to 126 are in the table `font5x7[c - 32]`.

**The waveform.** Each sample is 0 to 4095 counts. Steps:

1. counts to millivolts: `mul_div(sample, 3300, 4095)`.
2. millivolts to rows above the bottom: `mul_div(mv, 8, vdiv_mv)`. (8 pixel rows per division.)
3. y = 63 minus those rows. Row 63 is 0 V.
4. Keep y inside 16 to 63 with `clamp_i`: that is "clipping".
5. Draw the pixel at (x, y). Also draw the vertical gap to the previous y, so square-wave edges look like edges.

**Clipping is a lesson.** At 500 mV/div the screen holds only 3.0 V, so a 3.3 V signal is clipped to the top row.

## Worked example: an 8-bar bar graph

```c
/* WORKED EXAMPLE (M3-03): an 8-bar bar graph on the 8x8 matrix. vals[x] is 0..255; bar height 0..8 rows. */
#include <stdint.h>
extern void m_pixel(unsigned x, unsigned y, int on);
extern uint32_t mul_div(uint32_t a, uint32_t b, uint32_t c);

static int clampi(int v, int lo, int hi) { return v < lo ? lo : (v > hi ? hi : v); }

void bars(const uint8_t *vals, unsigned n)
{
    for (unsigned x = 0; x < n && x < 8; x++) {
        int h = clampi((int)mul_div(vals[x], 8, 255), 0, 8);     /* height in rows     */
        for (int r = 0; r < h; r++) {
            m_pixel(x, 7u - (unsigned)r, 1);                     /* grow upward from row 7 */
        }
    }
}
```

Same chain as your `plot_wave`: scale with `mul_div`, keep in range with a clamp, then plot pixels column by column.

## Cheat sheet

| Item | Value |
|---|---|
| Text rows | rows 0 to 15: line 1 at y = 0, line 2 at y = 8 |
| Plot rows | 16 to 63. Row 63 = 0 V |
| Grid | horizontal dotted lines at y = 16, 24, 32, 40, 48, 56, 63, a dot at every 4th x (0, 4, 8, ...). Vertical dotted lines at x = 0, 16, 32, 48, 64, 80, 96, 112 and 127, a dot at every even y from 16 to 62 |
| Font | `font5x7[95][5]` given. Index = character - 32. Bit 0 of a column byte = top row |
| Glyph 'A' | columns `7E 11 11 11 7E` |
| Character width | 5 columns + 1 gap = advance 6 |
| Clip text | `fb_pixel` already ignores x >= 128 |
| `plot_wave(s, n, vdiv_mv)` | n at most 128 samples. For x = 0..n-1: `mv = mul_div(s[x], 3300, 4095)`, `rows = mul_div(mv, 8, vdiv_mv)`, `y = clamp_i(63 - rows, 16, 63)` |
| Vertical join | draw all y from `min(prev, y)` to `max(prev, y)` in column x (just `y` for x = 0) |
| Examples | 4095 counts at 1000 mV/div: mv 3300, rows 26, y 37. At 500 mV/div: rows 52, y = 11 -> clamped to 16. 0 counts: y 63 |
| `clamp_i(v, lo, hi)` | `if (v < lo) return lo; if (v > hi) return hi; return v;` |
| Drawing functions | `fb_pixel(x, y, on)`, `fb_clear()` (M3-02) |

Card C5: `mul_div(a, b, c)` = a * b / c in 64 bits.

for (; *<S>; <S>++) {
    unsigned c = (unsigned char)*<S>;
    if (c >= 32u && c <= 126u) {
        const uint8_t *g = font5x7[c - 32u];          /* the 5 column bytes */

| name | meaning |
|---|---|

| `1u << row` | the bit for one row (bit 0 = top) |
| `x += 6u` | next character starts 6 px right |

- **INGREDIENTS:** `mul_div`, `clamp_i`, `fb_pixel`.
- **HOW:**

```
int prev = 0;
if (n > 128u) n = 128u;
for (unsigned x = 0; x < n; x++) {
    uint32_t mv   = mul_div(s[x], <FULL MV>, <FULL COUNTS>);
    uint32_t rows = mul_div(mv, <ROWS PER DIV>, vdiv_mv);

}
```

| ROWS PER DIV | `8u` |
| TOP / BOTTOM | `16` / `63` |
