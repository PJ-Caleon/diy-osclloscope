## Learn (about 30 minutes)

**Buttons bounce.** A metal contact does not close cleanly: it chatters for a few milliseconds. Read it raw and one press looks like 5 presses.

**Debounce rule.** Only believe a new state once the pin has held the same value for 20 ms. Keep three things per button: `stable` (what you believe), `last` (the latest raw reading) and `t_change` (when `last` last changed). Each call:

1. If raw differs from `last`: remember it and the time. Not stable yet. Return 0.
2. Else if raw differs from `stable` and the pin has held for 20 ms (`elapsed(now, t_change) >= 20`): accept it: `stable = raw`. Return `raw` (so you get 1 only for a press).
3. Otherwise return 0.

That uses card C6 (`elapsed`) so it survives the millis wrap.

**Active-low buttons.** The button connects the pin to GND. The internal pull-up holds it HIGH when open. So pressed = 0. `buttons_read` inverts the pins so that 1 = pressed.

**Pull-up recipe on the F103.** Nibble 0x8 means "input with pull". The ODR bit then chooses: ODR = 1 gives pull-UP. You set ODR bits through BSRR.

**State machine in a table.** Each row says: "if I am in MODE m and event e happens, run action a, then go to mode n." One loop finds the row. Adding a feature = adding a row, not rewriting code.

| mode | MODE button | UP | DOWN |
|---|---|---|---|
| M_TDIV (T) | go to M_VDIV | tdiv index +1 | tdiv index -1 |
| M_VDIV (V) | go to M_LEVEL | vdiv index +1 | vdiv index -1 |
| M_LEVEL (L) | go to M_EDGE | level +100 mV | level -100 mV |
| M_EDGE (E) | go to M_TDIV | toggle rising/falling | toggle rising/falling |

## Worked example: a one-button debouncer plus a traffic-light state table

```c
/* WORKED EXAMPLE (M4-03): a one-button debouncer plus a traffic-light state table. */
#include <stdint.h>
#include <stddef.h>

/* ---- debouncer: a press counts once the pin has been steady for 20 ms ---- */
typedef struct { uint8_t stable, last; uint32_t t_change; } deb_t;
static uint32_t elapsed(uint32_t now, uint32_t start) { return now - start; }

int deb_update(deb_t *d, int raw, uint32_t now)
{
    raw = (raw != 0);
    if (raw != d->last) { d->last = (uint8_t)raw; d->t_change = now; return 0; }   /* it moved: restart the timer */
    if (raw != d->stable && elapsed(now, d->t_change) >= 20u) { d->stable = (uint8_t)raw; return raw; }
    return 0;
}

/* ---- state table: {current state, event, next state} ---- */
typedef enum { RED, GREEN, YELLOW } light_t;
typedef enum { EV_PRESS, EV_TIMEOUT } ev_t;
typedef struct { light_t state; ev_t ev; light_t next; } row_t;
static const row_t table[] = {
    { RED,    EV_PRESS,   GREEN  },
    { GREEN,  EV_TIMEOUT, YELLOW },
    { YELLOW, EV_TIMEOUT, RED    },
};

light_t light_handle(light_t s, ev_t ev)
{
    for (unsigned i = 0; i < sizeof table / sizeof table[0]; i++) {
        if (table[i].state == s && table[i].ev == ev) return table[i].next;   /* found the row */
    }
    return s;                                                                 /* no row: stay  */
}
```

`deb_update` is your `debounce_update`. `table` and `light_handle` are your `ui_table` and `ui_handle`: loop over rows, match, return the next state.

## Cheat sheet

| Item | Value |
|---|---|
| Debounce time | `DEBOUNCE_MS` = 20 |
| `debounce_t` | `{ uint8_t stable; uint8_t last; uint32_t t_change; }` |
| Events | `EV_NONE` 0, `EV_MODE` 1, `EV_UP` 2, `EV_DOWN` 3 |
| Modes | `M_TDIV`, `M_VDIV`, `M_LEVEL`, `M_EDGE` |
| Ranges | tdiv index 0..7 (`TDIV_COUNT - 1`), vdiv index 0..2 (`VDIV_COUNT - 1`), level 0..3300 mV in steps of 100 |
| Action rules | tdiv and vdiv: `step_index(current, +1 or -1, max)`. Level: `clamp_i(level +/- 100, 0, 3300)`. Edge: flip `rising` |
| Table row type | `ui_row_t { mode, ev, action, next }` (given) |
| Table | `ui_table[]` (given), 12 rows |
| Buttons | PB12 MODE, PB13 UP, PB14 DOWN. GPIOB clock = APB2ENR bit 3 (`RCC_APB2ENR_IOPBEN`). PB12 is CRH shift 16, PB13 shift 20, PB14 shift 24 |
| Nibble | 0x8 = input with pull-up/pull-down. BSRR bits 12, 13, 14 = pull-UP |
| GPIOB | `GPIOB->IDR` offset 0x08, `GPIOB->BSRR` offset 0x10 |
| `buttons_read` | read IDR, invert, shift right 12, mask with 7 |

Card C6: `elapsed = now - start;` and card C2: `gpio_cfg(GPIOx, pin, NIBBLE)`.

### STEP 1 · TODO M4-03/1 · `debounce_update` · card C6 · [src: M4-03 step 1, card C6, worked example deb_update]
- **WHAT:** Turn a bouncing pin into one clean press event.
- **INGREDIENTS:** `elapsed`, `DEBOUNCE_MS`, the three fields of `debounce_t`.
- **HOW (recipe):**
  1. Turn `raw` into exactly 0 or 1.
  2. If `raw` differs from the `last` field: store it in `last`, store `now_ms` in `t_change`, return 0.
  3. Else, if `raw` differs from the `stable` field AND `elapsed(now_ms, t_change)` is at least `DEBOUNCE_MS`: store `raw` in `stable` and return `raw`.
  4. Otherwise return 0.

| time (ms) | raw | returns |
|---|---|---|
| 0 | 1 | 0 |
| 10 | 1 | 0 |
| 20 | 1 | 1 (the press) |
| 30 | 1 | 0 |

This is card C6 again (`elapsed`) with a 20 ms limit. `d->last` means "the field `last` of the struct that `d` points to".
- **WHERE:** `src/ui.c`, `debounce_update`.
- **CHECK:** `make t T=m4_03` -> `test_debounce_clean_press`, `test_debounce_bounce`, `test_debounce_wrap` all `:PASS`.

### STEP 3 · TODO M4-03/3 · `ui_handle` · [src: M4-03 step 3, worked example light_handle]
- **WHAT:** Find the row, run its action, change mode.
- **INGREDIENTS:** `ui_table`, `ui_row_t`.
- **HOW (recipe):**
  1. Loop `i` over the rows of `ui_table` (row count = `sizeof ui_table / sizeof ui_table[0]`, which is 12).
  2. Find the row whose `mode` equals `u->mode` AND whose `ev` equals the argument `ev`.
  3. In that row: if `action` is not NULL, call it with `u`. Then set `u->mode` to the row's `next`. Stop (return).
  4. If no row matches, change nothing.

| mode | event | action | next |
|---|---|---|---|
| `M_TDIV` | `EV_UP` | `act_tdiv_up` | `M_TDIV` |
| `M_TDIV` | `EV_MODE` | none (NULL) | `M_VDIV` |

`ui_table[i].action(u)` calls the function stored in the row (a function pointer), as `light_handle` in the example returns the stored next state.
- **WHERE:** `src/ui.c`, `ui_handle`.
- **CHECK:** `make t T=m4_03` -> `test_ui_tdiv`, `test_ui_mode_cycle`, `test_ui_vdiv_level_edge`, `test_ui_none_event` all `:PASS`.

### STEP 5 · TODO M4-03/5 · `buttons_read` · [src: M4-03 step 5]
- **WHAT:** Read the three buttons as a 3-bit mask (1 = pressed).
- **INGREDIENTS:** `GPIOB->IDR`, inversion `~`, shift 12, mask 7.
- **HOW (recipe):**
  1. Read `GPIOB->IDR`.
  2. Invert it (pressed pins read 0).
  3. Shift right by 12 so PB12 becomes bit 0.
  4. Keep only the lowest 3 bits (mask 7).
  5. Return that as `uint8_t`.

| pins (PB14 PB13 PB12) | IDR bits | result |
|---|---|---|
| none pressed | 111 | 0 |
| MODE pressed | 110 | 1 |
| UP pressed | 101 | 2 |
| DOWN pressed | 011 | 4 |
- **WHERE:** `src/ui.c`, `buttons_read`. Delete the stub `return 0;`.
