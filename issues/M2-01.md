**Card C3  Wait for a flag with a timeout**

```
while (tries--) {
    if ((*reg & MASK) is in the wanted state) return 0;   /* flag came */

return -1;                                                /* gave up   */
In code:  if (wait_flag(&REG, MASK, WANT_SET, TRIES)) { /* timed out */ }
```

**Card C1  Change a field (clear with a mask, then set)**

```
REG &= ~(MASK << SHIFT);     /* 1. clear the field  */
REG |=  (VALUE << SHIFT);    /* 2. write the value  */
MASK = (1 << WIDTH) - 1      /* width 1 -> 0x1, 2 -> 0x3, 3 -> 0x7, 4 -> 0xF */
In code:  reg = field_set(reg, SHIFT, WIDTH, VALUE);
```



## Learn (about 30 minutes)

**An ADC measures a voltage as a number.** 12 bits = 0 to 4095. 0 counts = 0 V, 4095 counts = 3.3 V. One count is about 0.8 mV.

**Sample time.** The ADC charges a tiny capacitor from the pin, then converts. A longer sample time suits a source that pushes weakly. Your pot (10k) wants a long time: we pick 41.5 ADC cycles (code 4). The register field is 3 bits per channel: SMPR2 for channels 0 to 9, SMPR1 for channels 10 to 17.

**Speed limit.** The ADC clock must be 14 MHz or less. 72 MHz divided by 6 = 12 MHz. One conversion = sample time + 12.5 cycles = 41.5 + 12.5 = 54 cycles = 4.5 microseconds.

**Calibration.** After switching the ADC on, wait a moment, then set CAL and wait for it to clear. It removes the chip's own offset error.

**Starting a conversion in software.** Set EXTTRIG = 1 with EXTSEL = 7 ("software start"), then set SWSTART each time. When the conversion is done, EOC (end of conversion) becomes 1. Reading DR gives the result and clears EOC.

**Card C5: multiply first, divide last.** counts to millivolts: `counts * 3300 / 4095`. If you divide first (`counts / 4095 * 3300`) the answer is nearly always 0. `mul_div` multiplies in 64 bits so nothing overflows.

**PA2 is analog.** Its pin nibble is 0x0. Never put more than 3.3 V on it.

## Worked example: TIM2 as a polled one-second timer

```c
/* WORKED EXAMPLE (M2-01): TIM2 as a one-second timer, read by polling. Same shape as an ADC read. */
#include "stm32f103.h"
#include "drills.h"

void tim2_start_1s(void)
{
    RCC->APB1ENR |= RCC_APB1ENR_TIM2EN;     /* 1. clock                          */
    TIM2->PSC = 7199u;                      /* 2. 72 MHz / 7200 = 10 kHz         */
    TIM2->ARR = 9999u;                      /*    10000 ticks = 1 second         */
    TIM2->EGR = TIM_EGR_UG;                 /*    load PSC now                   */
    TIM2->SR  = 0u;                         /*    clear the update flag          */
    TIM2->CR1 |= TIM_CR1_CEN;               /* 3. start                          */
}

int tim2_wait_1s(void)                      /* 4. wait for the update flag       */
{
    if (wait_flag(&TIM2->SR, BIT(0), 1, 50000000u)) return -1;
    TIM2->SR = 0u;                          /* 5. clear the flag by writing 0    */
    return 0;
}
```

Same shape as your ADC read: clock, configure, start, wait (card C3), clear.

## Cheat sheet

| Item | Value |
|---|---|
| ADC1 base | 0x40012400 |
| ADC offsets | SR 0x00, CR1 0x04, CR2 0x08, SMPR1 0x0C, SMPR2 0x10, SQR1 0x2C, SQR2 0x30, SQR3 0x34, DR 0x4C |
| ADC clock | `RCC->CFGR` ADCPRE: shift 14, width 2, value 2 (= divide by 6) |
| Clock bits in APB2ENR | GPIOA bit 2, ADC1 bit 9 |
| PA2 | CRL nibble 0x0 (analog input), shift 8 |
| SMPR2 field for channel 2 | shift `smpr_field(2)` = 6, width 3, value 4 (41.5 cycles) |
| Sample-time codes | 0 = 1.5, 1 = 7.5, 2 = 13.5, 3 = 28.5, 4 = 41.5, 5 = 55.5, 6 = 71.5, 7 = 239.5 cycles |
| SQR3 | field SQ1: shift 0, width 5, value 2 (channel 2). SQR1 length field stays 0 (one conversion) |
| CR2 bits | ADON bit 0, CAL bit 2, EXTSEL shift 17 width 3, EXTTRIG bit 20, SWSTART bit 22 |
| EXTSEL = 7 | software start |
| SR bit | EOC = bit 1 |
| Order | clocks, ADCPRE, pin, SMPR2, SQR3, ADON, short wait, CAL + wait for CAL = 0, EXTSEL = 7 + EXTTRIG |
| Short wait | `for (volatile int i = 0; i < 1000; i++) { }` |
| counts to mV | `mul_div(raw, 3300u, 4095u)` |
| smpr_field | channel < 10 ? channel * 3 : (channel - 10) * 3 |
| Names in the header (given) | `RCC_APB2ENR_IOPAEN`, `RCC_APB2ENR_ADC1EN`, `RCC_CFGR_ADCPRE_Pos`, `ADC_CR2_ADON`, `ADC_CR2_CAL`, `ADC_CR2_EXTSEL_Pos`, `ADC_CR2_EXTTRIG`, `ADC_CR2_SWSTART`, `ADC_SR_EOC` |
| Expect from wires | PA2 on GND: 0 to about 10 counts. PA2 on 3V3: about 4080 to 4095 |

Cards C1, C3, C5:

```
C1: reg = field_set(reg, SHIFT, WIDTH, VALUE);
C3: if (wait_flag(&REG, MASK, WANT_SET, TRIES)) { /* timed out */ }
C5: mul_div(a, b, c) = a * b / c in 64 bits
```

```
RCC->APB2ENR |= <CLOCKS>;                                           /* C4 clock    */
RCC->CFGR = field_set(RCC->CFGR, <ADCPRE SHIFT>, 2u, <ADCPRE>);     /* C1          */
gpio_cfg(GPIOA, <PIN>, <NIBBLE>);                                   /* C2          */
```

| name | value |

| PIN / NIBBLE | `2u` / `0x0u` |
| CH | `2u` |
| CODE (41.5 cycles) | `4u` |
| EXTSEL | `7u` |

This is card C1 again three times (shifts 14, 6, 0 with widths 2, 3, 5) and the last line a fourth time (shift 17 width 3 value 7).

## Verify

| Do this | Expect |
|---|---|
| `make t T=m2_01` | `5 Tests 0 Failures 0 Ignored`, `OK` |
| Wire PA2 to GND (unplug USB first), flash | `raw` is 0 to about 10, `mv` 0 to about 8 |

| Wire the pot: outer pins to 3V3 and GND, middle to PA2; turn the knob | `raw` sweeps smoothly from near 0 to near 4095 |
| Leave PA2 unconnected | readings wander: a floating pin is not a voltage |

| If it fails, look here | Likely cause |
|---|---|
| `raw` always 0 | the ADC1 clock bit (APB2ENR bit 9) is missing, or PA2 nibble is not 0x0 |
| `raw` always 4095 or stuck | `CAL` not waited for, or channel not 2 (`SQR3`) |
| no output lines | `adc_read` timed out (-1): is ADON set? is `EXTTRIG` + `EXTSEL` = 7 in place? |
| readings jump by 30 or more | sample time too short: check you wrote code 4 in the field `smpr_field(2)` |
| `mv` near 0 even at 3V3 | `adc_to_mv` divides first: use `mul_div` |
