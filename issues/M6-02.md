## Learn (about 30 minutes)

**No instrument is perfect.** Two things drift: the ADC reads a few counts at 0 V (offset) and may read less than 4095 at 3.3 V (gain). A two-point calibration measures both ends and rescales between them.

**You have no multimeter, but you have two exact voltages.** GND is 0 V. The 3V3 pin is 3.3 V (as accurate as your regulator). Measure the ADC at each. Those two readings are your calibration points.

**The rescale.** `corrected = (raw - offset) * 4095 / span`, where `span = counts at 3V3 minus counts at GND`. That maps your two readings to exactly 0 and 4095. Use card C5, and keep the result inside 0..4095 with `clamp_i`. If `raw` is below the offset the subtraction would wrap around (unsigned): return 0 first.

**Sanity rule.** If the two readings are less than 2000 counts apart you wired something wrong. Reject.

**Check with a known signal.** Your PWM at 25 % should read an average near 0.82 V and a frequency of 1.00 kHz within 2 %.

**Shipping.** A project is done when a stranger can read the README, see CI green, and find a tag.

## Cheat sheet

| Item | Value |
|---|---|
| `cal_t` | `{ uint16_t offset; uint16_t span; }` |
| Default | `{ 0, 4095 }` (does nothing: `cal_apply` returns the sample unchanged) |
| `cal_fit` | offset = reading at GND; span = reading at 3V3 minus reading at GND; reject if span is under 2000 |
| `cal_apply` | corrected = (raw - offset) x 4095 / span; 0 if raw is at or below offset; clamp to 0..4095 |
| Example | `cal_t c = {5, 4085}`: `cal_apply(c, 5)` = 0; `4090` = 4095; `4095` = 4095 (clamped); `2047` = 2046 |

### STEP 1 · TODO M6-02/1 · `cal_fit` · [src: M6-02 step 1]
- **WHAT:** Turn two readings into offset and span.
- **INGREDIENTS:** the sanity rule (2000 counts).
- **HOW (recipe):**
  1. If `raw_3v3` is less than `raw_gnd + 2000`: return -1 and leave `*c` unchanged.
  2. Store `raw_gnd` in `c->offset`.
  3. Store `raw_3v3 - raw_gnd` in `c->span` (cast to `uint16_t`).
  4. Return 0.

| raw_gnd | raw_3v3 | result |
|---|---|---|
| 5 | 4090 | offset 5, span 4085, returns 0 |
| 4000 | 4090 | returns -1, `c` unchanged |
- **WHERE:** `src/cal.c`, `cal_fit`. Delete the stub lines.
- **CHECK:** `make t T=m6_02` -> `test_fit:PASS`.

### STEP 2 · TODO M6-02/2 · `cal_apply` · card C5 · [src: M6-02 step 2, card C5, drill clamp_i]
- **WHAT:** Rescale one raw sample.
- **INGREDIENTS:** `mul_div`, `clamp_i`.
- **HOW (recipe):**
  1. If `raw` is at or below `c->offset`: return 0 (this avoids an unsigned wrap-around).
  2. Otherwise compute `mul_div(raw - offset, 4095, span)`.
  3. Keep the result inside 0..4095 with `clamp_i`.

| {5, 4085} | 4090 | 4095 |
| {5, 4085} | 4095 | 4095 (clamped) |
