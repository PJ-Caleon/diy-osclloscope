## Learn (about 30 minutes)

**Frequency = how many periods per second.** You measure the time between repeats. Pick a repeating event: the signal crossing a level going UP. The distance between two such crossings is one period.

**Use all the crossings.** One period measured from two neighbours is rough (one sample of error is a big fraction). Instead take the first crossing and the last crossing: `last - first` samples cover `count - 1` periods. Average period = `(last - first) / (count - 1)` samples. Frequency = `fs / average period = fs * (count - 1) / (last - first)`. Multiply first, divide last (card C5): `mul_div(fs, count - 1, last - first)`.

**Example.** PWM 1 kHz sampled at 32 kHz: a period is 32 samples. 8 periods fit in 256 samples. Crossings might be at 27, 59, ..., 251 (8 of them). `fs * 7 / 224 = 32000 * 7 / 224 = 1000`.

**What level?** The scope uses the midpoint `(min + max) / 2`, so any signal crosses it.

**Fewer than two crossings: answer 0.**

**Text without printf.** `fmt_mv` shows volts with two decimals, rounded to the nearest 10 mV: `v = (mv + 5) / 10` hundredths; whole = `v / 100`, then `.`, then two digits `(v % 100) / 10` and `v % 10`, then `V`. `fmt_hz` below 1000 prints the number and `Hz`; from 1000 prints kHz with two decimals the same way. A helper `put_hundredths(out, v)` is already given in `fmt.c`: it writes `whole.dd` and returns the length.

## Worked example: a zero-crossing period

```c
/* WORKED EXAMPLE (M5-02): average period (in samples) of a signal from its upward zero crossings. */
#include <stdint.h>
/* Returns the period in samples times 16 (4 fractional bits), or 0 if there are fewer than 2 crossings. */
uint32_t zc_period_x16(const int16_t *s, unsigned n)
{
    unsigned first = 0, last = 0, count = 0;
    for (unsigned i = 1; i < n; i++) {
        if (s[i - 1] < 0 && s[i] >= 0) {          /* an upward crossing           */
            if (count == 0) first = i;            /* remember the first one       */
            last = i;                             /* always remember the latest   */
            count++;
        }
    }
    if (count < 2) return 0;
    return (uint32_t)(((uint64_t)(last - first) * 16u) / (count - 1u));   /* multiply first, divide last */
}
```

Yours is the same scan, except the crossing test uses `level` (not zero), the result is Hz, and there is no fixed-point fraction.

## Cheat sheet

| Item | Value |
|---|---|
| Rising crossing at i | `s[i-1] < level && s[i] >= level` (i from 1) |
| Remember | `first` (index of crossing #1), `last` (latest), `count` |
| Result | `count < 2` -> 0; else `mul_div(fs_hz, count - 1u, last - first)` |
| `fmt_mv` | hundredths = (mv + 5) / 10; `put_hundredths`, then the letter `V`, then a 0 byte; return the length |
| `fmt_mv` examples | 3300 -> `3.30V`; 824 -> `0.82V`; 1650 -> `1.65V`; 5 -> `0.01V`; 4 -> `0.00V`; 0 -> `0.00V` |
| `fmt_hz` below 1000 | number with `fmt_u32`, then `Hz` |
| `fmt_hz` from 1000 | hundredths = (hz + 5) / 10; `put_hundredths`, then `kHz` |
| `fmt_hz` examples | 1000 -> `1.00kHz`; 999 -> `999Hz`; 800 -> `800Hz`; 0 -> `0Hz`; 1006 -> `1.01kHz`; 40000 -> `40.00kHz`; 12345 -> `12.35kHz` |
| Given helpers | `put_str(out, "text")` returns the length; `put_hundredths(out, v)` writes `v` hundredths and returns the length; `fmt_u32(out, v)` |
| Return value | the number of characters written (not counting the 0 byte) |

### STEP 1 · TODO M5-02/1 · `measure_freq` · card C5 · [src: M5-02 step 1, card C5, worked example zc_period_x16]
- **WHAT:** Frequency from the spacing of rising crossings.
- **INGREDIENTS:** the crossing test, `first`, `last`, `count`, `mul_div`.
- **HOW (recipe):**
  1. Keep three counters: `first`, `last`, `count`, all 0 at the start.
  2. Loop `i` from 1 to `n - 1`. A rising crossing is: sample `i - 1` below `level` AND sample `i` at or above `level`.
  3. At a crossing: if `count` is 0 then `first = i`. Always set `last = i`. Add 1 to `count`.
  4. After the loop: if `count` is less than 2 return 0.
  5. Otherwise return `mul_div(fs_hz, count - 1, last - first)`.

| signal | crossings | result |
|---|---|---|
| period 32 samples, 8 periods, fs 32000 | 7 or 8 | 1000 |
| period 16 samples, fs 16000 | 15 | 1000 |
| flat line | 0 | 0 |
| one step up | 1 | 0 |

This is card C5 again, with (fs, count - 1, last - first).
