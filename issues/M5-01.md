## Learn (about 30 minutes)

**Three numbers describe a repeating signal:** the lowest value (min), the highest (max) and the mean (average).

**Vpp** = peak-to-peak = max minus min. A signal that swings 0 V to 3.3 V has Vpp 3.3 V.

**Average** = sum of all samples divided by how many there are. A 25 % duty pulse of 3.3 V averages about 0.825 V. That is how you check your PWM without a multimeter.

**Overflow trap.** 256 samples of up to 4095 add up to 1,048,320. That does not fit in 16 bits but fits easily in 32. Use a `uint32_t` sum. Divide LAST.

**Starting values.** Start min and max from the FIRST sample, not from 0 or 4095. A starting min of 0 would never be beaten.

**Unit conversion** at the end (card C5): counts to millivolts with `mul_div`. Do the maths on counts first, convert once.

## Worked example: statistics over a temperature array

```c
/* WORKED EXAMPLE (M5-01): min, max, average over an array of temperatures in tenths of a degree. */
#include <stdint.h>
typedef struct { int16_t min, max; int32_t avg; } tstats_t;

void temp_stats(const int16_t *t, unsigned n, tstats_t *out)
{
    int16_t mn = t[0], mx = t[0];       /* start from the FIRST value, not from 0 */
    int32_t sum = 0;
    for (unsigned i = 0; i < n; i++) {
        if (t[i] < mn) mn = t[i];
        if (t[i] > mx) mx = t[i];
        sum += t[i];
    }
    out->min = mn;
    out->max = mx;
    out->avg = sum / (int32_t)n;        /* divide LAST */
}
```

Same loop with different data: tenths of a degree instead of ADC counts.

## Cheat sheet

| Item | Value |
|---|---|
| `stats_t` | `{ uint16_t min; uint16_t max; uint32_t avg; }` in counts |
| Loop | over all `n` samples, index `i` from 0 |
| Start | `mn` and `mx` from the first sample; `sum` is a 32-bit variable starting at 0 |
| Update | smaller than `mn`: replace it; larger than `mx`: replace it; always add to `sum` |
| End | store `mn`, `mx`, and `sum` divided by `n` (divide LAST) |
| `stats_vpp_mv` | (max - min) counts x 3300 / 4095 with `mul_div` |
| `stats_avg_mv` | avg counts x 3300 / 4095 with `mul_div` |
| Examples | min 0, max 4095, avg 1023: Vpp 3300 mV, avg 824 mV. Difference 2048 counts = 1650 mV |
| PWM test signal | real captures show min 0 to about 10, max about 4085 to 4095, avg about 1023 (824 mV) |

| If it fails, look here | Likely cause |
|---|---|
| min is always 0 | min started at 0 instead of `s[0]` |
| avg is wrong or negative | sum is a `uint16_t` (overflow): use `uint32_t` |
| Vpp is 0 | you subtracted the wrong way round, or used avg |
| avg off by one | integer division truncates: that is allowed (the test uses a tolerance only for the PWM case) |
