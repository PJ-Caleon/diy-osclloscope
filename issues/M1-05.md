**Card C3  Wait for a flag with a timeout**

```
while (tries--) {
    if ((*reg & MASK) is in the wanted state) return 0;   /* flag came */
}
return -1;                                                /* gave up   */
In code:  if (wait_flag(&REG, MASK, WANT_SET, TRIES)) { /* timed out */ }
```

Ring a doorbell up to N times. If nobody comes, walk away. Never ring forever.

```
wait_flag(&USART1->SR, USART_SR_TXE, 1, 100000u)   -> 0 when TXE became 1, -1 if not
wait_flag(&I2C1->SR2, I2C_SR2_BUSY, 0, 20000u)       -> waits for BUSY to become 0
```

| call | returns |
|---|---|
| flag already in the wanted state | 0 |
| flag never arrives, tries = 5 | -1 after 5 reads |
| tries = 0 | -1 at once |

**Card C6  Wrap-safe time compare**

```
elapsed = now - start;                    /* unsigned subtraction survives the wrap */
reached = (int32_t)(now - deadline) >= 0; /* sign of the difference                 */
NEVER write:  now >= deadline
```

A car odometer that rolls over from 999999 to 000000. The distance driven is still new minus old.

```
elapsed(5, 0xFFFFFFF0) = 21
reached(5, 0xFFFFFFF0) = 1      (the deadline was just before the wrap)
```

| now | start / deadline | elapsed | reached |
|---|---|---|---|
| 100 | 40 | 60 | 1 |
| 9 | 10 | (wraps: huge) | 0 |
| 5 | 0xFFFFFFF0 | 21 | 1 |



## Learn (about 30 minutes)

**UART** sends bytes one bit at a time on one wire. No clock wire: both sides agree on a speed (the baud rate). 115200 baud = 115200 bits per second. A byte takes 10 bits (start, 8 data, stop).

**Baud register.** The chip divides its bus clock to make the bit clock: `BRR = pclk / baud`. USART1 is on APB2 (72 MHz): 72,000,000 / 115,200 = 625. Round to the nearest whole number.

**Bring-up (card C4):** clock (GPIOA and USART1), pin (PA9 = TX, alternate-function push-pull; PA10 = RX, floating input), configure (BRR), start (UE, TE, RE).

**Sending a byte:** wait until TXE (transmit data register empty) is 1, then write the byte to DR. That wait is card C3.

**No printf.** There is no C library. You write `fmt_u32` yourself: take the number apart with `% 10` (the digits come out backwards), then copy them out in reverse order.

**Wires.** Adapter RX goes to board PA9 (a transmitter talks into a receiver, so TX meets RX). Adapter TX to board PA10. GND to GND. Adapter power pin NOT connected.

## Worked example: USART2 on PA2 and PA3

```c
/* WORKED EXAMPLE (M1-05): USART2 on PA2 (TX) / PA3 (RX). USART2 hangs on the SLOWER bus (APB1, 36 MHz). */
#include "stm32f103.h"
#include "drills.h"

#define RCC_APB1ENR_USART2EN BIT(17)

void usart2_init(void)
{
    RCC->APB2ENR |= RCC_APB2ENR_IOPAEN;                 /* 1. clocks: GPIOA ...        */
    RCC->APB1ENR |= RCC_APB1ENR_USART2EN;               /*    ... and USART2           */
    gpio_cfg(GPIOA, 2, 0xB);                            /* 2. PA2 alternate push-pull  */
    gpio_cfg(GPIOA, 3, 0x4);                            /*    PA3 floating input       */
    USART2->BRR = brr_for(36000000u, 115200u);          /* 3. 36 MHz / 115200 = 313    */
    USART2->CR1 = USART_CR1_UE | USART_CR1_TE | USART_CR1_RE;   /* 4. start            */
}

void usart2_putc(char c)
{
    if (wait_flag(&USART2->SR, USART_SR_TXE, 1, 100000u)) return;   /* 5. wait */
    USART2->DR = (uint32_t)(uint8_t)c;
}
```

Differences from yours: USART2 sits on the slower APB1 bus (36 MHz, BRR 313), and uses pins PA2 and PA3.

## Cheat sheet

| Item | Value |
|---|---|
| USART1 base | 0x40013800 |
| USART offsets | SR 0x00, DR 0x04, BRR 0x08, CR1 0x0C, CR2 0x10, CR3 0x14 |
| SR bits | RXNE bit 5, TC bit 6, TXE bit 7 |
| CR1 bits | RE bit 2, TE bit 3, UE bit 13 |
| Clock bits in APB2ENR | GPIOA bit 2, USART1 bit 14 |
| Pins | PA9 TX: nibble 0xB (alternate push-pull 50 MHz). PA10 RX: nibble 0x4 (floating input) |
| BRR | `(pclk + baud / 2) / baud`. 72 MHz, 115200 -> 625. 36 MHz, 115200 -> 313 (312.5 rounds up) |
| Banner text | `SCOPE v0.1 clk=` + `72000000` + CR LF (`\r\n`) |
| Names in the header (given) | `RCC_APB2ENR_IOPAEN`, `RCC_APB2ENR_USART1EN`, `USART_SR_TXE`, `USART_CR1_UE`, `USART_CR1_TE`, `USART_CR1_RE`, `SYSCLK_HZ` |
| picocom | `picocom -b 115200 /dev/ttyUSB0`; leave with Ctrl-A, Ctrl-X |
| fmt_u32 shape | collect `v % 10` digits into `tmp[]` (backwards), `v /= 10`, then copy `tmp` out in reverse; end with a 0 byte |
| Return value | every `fmt_` function returns the length (not counting the 0 byte) |

### STEP 2 · TODO M1-05/2 · `fmt_u32` · [src: M1-05 step 2]
- **WHAT:** Turn a number into text.
- **INGREDIENTS:** `% 10`, `/ 10`, a 10-character array (a uint32 has at most 10 digits).
- **HOW:**

```
char tmp[10];
unsigned n = 0, len = 0;
do {
    tmp[n++] = (char)('0' + (v % 10u));   /* last digit as a letter */
    v /= 10u;                              /* drop the last digit    */
} while (v != 0u);                         /* do-while: 0 still prints "0" */
while (n > 0u) out[len++] = tmp[--n];      /* copy out, reversed     */
out[len] = 0;
return len;
```

| v | tmp (backwards) | out |
|---|---|---|
| 123 | '3','2','1' | "123" |
| 0 | '0' | "0" |
